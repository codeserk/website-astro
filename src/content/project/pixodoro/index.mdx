A pomodoro timer that looks like it came out of a Game Boy. It's literally a timer, so it's free, and it runs on every screen I have.

## Content

## Why

There are plenty of pomodoro apps - [Forest](https://www.forestapp.cc/), [Be Focused Pro](https://apps.apple.com/app/be-focused-pro/id961632517), [Focus Keeper Pro](https://apps.apple.com/app/focus-keeper-pro/id867374917) - and most of them want a subscription for themes, stats or sync. For a thing that counts to 25 minutes.

The other reason is that I wanted an excuse to build the same app four times.

## Everywhere

It's a monorepo, and all the business logic - the timer, the phases, the history, the settings - lives in a `core` that knows nothing about the screen it will end up on. Every platform is views on top of it:

- **Web**, [](framework/react) Native for Web, installable as a `PWA`.
- **Mobile**, [](framework/react-native) with `Expo`, [](development/android) and [](development/ios).
- **Desktop**, `Wails` with a [](language/golang) backend, living in the menu bar and hiding itself when it loses focus.
- **Terminal**, a prototype with [Ink](https://github.com/vadimdemedes/ink) reusing the same stores, mostly because I wanted to know if it would work. It did.

So a feature gets written once, in the core, and then it exists everywhere. Bringing it to another platform is adapting views, not re-implementing anything. The terminal build is the proof that it works: same core, same stores, rendered with text instead of pixels.

## What it does

Configurable work, break and long break phases, session history with daily goals, sounds and ticking, notifications when a phase ends, keyboard shortcuts, English and Spanish, light and dark theme, onboarding, and an in-app changelog.

Sync is through Google Drive, encrypted client side. It's your drive, I never see anything, and I don't have to run a server for it.
