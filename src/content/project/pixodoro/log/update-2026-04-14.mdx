First day. `@wren/core` with the stores and their `jest` tests, then a web app on [](framework/react) Native for Web with React Router, and `Playwright` specs running on `WebKit` from the beginning.

Same afternoon the `Expo` app got scaffolded on top of the same stores. Doing web and mobile on day one was on purpose: if the core can't serve both from the start, it never will later, it just accumulates web assumptions.
