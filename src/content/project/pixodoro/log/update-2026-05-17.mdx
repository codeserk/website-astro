Phase-end notifications are scheduled now instead of fired while the app is alive. A pomodoro timer you have to keep in the foreground is not a pomodoro timer.

The history got a flex layout and a 1000 day window, the mobile Google client is per build so debug and release don't fight over the same credentials, and there is an `IAP` coffee counter for whoever wants to pay for something that is free.

Analytics go to [](project/forge), which is the first time I use my own thing for something that is not itself.
